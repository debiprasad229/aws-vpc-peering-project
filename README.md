# AWS VPC Peering Project

## Project Overview

This project demonstrates AWS VPC Peering to enable private IPv4 communication between EC2 instances in two separate Virtual Private Clouds (VPCs).

## Architecture

- **VPC A:** `10.10.0.0/16`
- **VPC B:** `10.20.0.0/16`
- **Public subnet:** `10.10.1.0/24`
- **Private subnet in VPC A:** `10.10.2.0/24`
- **Private subnet in VPC B:** `10.20.1.0/24`

## Technologies and Services

- Amazon VPC
- VPC Peering
- Amazon EC2
- Route Tables
- Security Groups
- SSH and ICMP connectivity testing

## Project Documentation

The completed project report contains the network configuration, route-table evidence, VPC peering configuration, EC2 instance details, connectivity tests, and cleanup screenshots.

## AWS Region

US East (N. Virginia) — `us-east-1`
